MATRIX-SDK 0.14.0 - QUICK REFERENCE FOR WASM BUILDS
================================================================================

SYNC METHODS (All async, return futures):
-----------
1. sync_once(settings)
   -> Result<SyncResponse>
   Single sync, returns immediately with response

2. sync(settings)
   -> Result<(), Error>
   Continuous loop until error. Use with add_event_handler()

3. sync_with_callback(settings, |response| async { LoopCtrl })
   -> Result<(), Error>
   Loop with callback receiving full SyncResponse each iteration

4. sync_with_result_callback(settings, |result| async { Result<LoopCtrl, Error> })
   -> Result<(), Error>
   Loop with error handling in callback

5. sync_stream(settings)
   -> impl Stream<Item = Result<SyncResponse>>
   Returns stream, used internally by callback methods

ROOM METHODS (All async):
-----------
send(content)                       -> SendMessageLikeEvent (builder pattern)
invite_user_by_id(&user_id)        -> Result<()>
invite_user_by_3pid(invite_id)     -> Result<()>
members(memberships)               -> Result<Vec<RoomMember>>
members_no_sync(memberships)       -> Result<Vec<RoomMember>>
send_state_event(content)          -> SendStateEvent
send_raw(request)                  -> SendRawMessageLikeEvent
send_attachment(body, config)      -> SendAttachment

ROOM LISTING (Non-async):
-----------
rooms()                            -> Vec<Room>
rooms_filtered(filter)             -> Vec<Room>
rooms_stream()                     -> (Vector<Room>, Stream<VectorDiff<Room>>)
joined_rooms()                     -> Vec<Room>
invited_rooms()                    -> Vec<Room>
left_rooms()                       -> Vec<Room>

CLIENT SETUP:
-----------
client.matrix_auth()               -> MatrixAuth (for login/logout)
client.account()                   -> Account
client.media()                     -> Media (NOT in WASM)
client.whoami()                    -> Result<Response>
client.create_room(request)        -> Result<Room>

AUTHENTICATION:
-----------
client.matrix_auth()
    .login_username(user, pass)
    .send()
    .await?

LOOP CONTROL (Used in callbacks):
-----------
LoopCtrl::Continue     -> Keep syncing
LoopCtrl::Break        -> Stop syncing

KEY DIFFERENCES FOR WASM:
------------------------
✓ Event handlers don't require Send + Sync bounds
✓ Can use Rc<RefCell<T>> (non-Send types) in handlers
✓ Single-threaded, no multi-threading concerns
✗ Media operations NOT available (no get_file, download_thumbnail)
✗ Must use homeserver URL directly for media in browser

TRAIT BOUNDS TO KNOW:
--------------------
SendOutsideWasm = Future that's Send on non-WASM, not Send on WASM
RoomMemberships = Flags for JOINED | INVITED | KNOCKED | LEFT | BANNED
LoopCtrl = Control enum for callback loops

COMMON PATTERNS:
---------------
1. Login + sync with handlers:
   client.matrix_auth().login_username(...).send().await?
   client.add_event_handler(|ev: Event| async { ... })
   client.sync(SyncSettings::default()).await?

2. Manual control:
   loop { client.sync_once(...).await? }

3. Get response objects:
   client.sync_with_callback(..., |response| async {
       response.rooms.joined
       response.rooms.invited
       LoopCtrl::Continue
   }).await?

4. Send message:
   room.send(RoomMessageEventContent::text_plain("Hi")).await?

5. Invite user:
   room.invite_user_by_id(&user_id).await?

6. List members:
   let members = room.members(RoomMemberships::ACTIVE).await?

WASM-SPECIFIC NOTES:
-------------------
- No threads, no Send/Sync required in handlers
- Media must be fetched through browser fetch API
- Use #[cfg(target_family = "wasm")] to conditionally compile
- Event dispatcher uses local task spawning
- AnyMap uses CloneAny (not CloneAnySendSync)
